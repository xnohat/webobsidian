# План локализации WebObsidian

**Цель.** Пользователь может подключить файл перевода Obsidian или перевести интерфейс WebObsidian с нуля. Оба сценария работают через один импорт.

**Требования.** В дистрибутив входит собственный английский каталог. Страница настроек содержит ссылку на официальный репозиторий. Пользователь сам скачивает файл и выбирает его на устройстве. Исходники, сборка и CI обходятся без включённых сторонних словарей. Сервер сохраняет явно импортированный пользователем пакет. Реализация использует TypeScript, React и существующий набор тестов Node.

**Границы первой версии.** Один активный импортированный пакет хранится в настройках сервера и применяется в браузерах этого экземпляра WebObsidian. Локальный кеш ускоряет старт. Повторный импорт заменяет пакет. Объём перевода охватывает собственный интерфейс веб-клиента, включая его использование внутри desktop-приложения. Публичные страницы, которые рендерит сервер, нативные меню Electron и интерфейсы сторонних плагинов находятся за пределами этого этапа.

**Хранение.** Сервер сохраняет явно импортированный файл через авторизованный API настроек. Упоминания локального хранения ниже описывают кеш. Сохранение на сервере предшествует применению нового языка. Ошибка сохраняет предыдущий язык. После входа, возвращения в окно и открытия настроек язык обновляется с сервера. Ранее локальный пакет переносится при отсутствии серверного. Явный серверный сброс имеет приоритет над старым кешем. Сторонние словари по-прежнему отсутствуют в исходниках и дистрибутиве.

## Результат проверки

Реализованы импорт, собственный каталог из 952 строк, шаблон, серверное хранение, локальный кеш, миграция и обновление при входе/возвращении в окно. Официальный ru.txt проверен целиком через обычный импорт и серверный обмен в памяти — 134 совпадающих ключа, 0 ошибок параметров. Для остальных строк работает английский резерв и собственный шаблон. Проверены 520 веб-тестов, 391 серверный тест, типы, production-сборка и интеграционный smoke. Веб-сценарии используют авторские фикстуры и временные хранилища.
